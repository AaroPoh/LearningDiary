25  SQL Peruskomennot

25.0.1 CREATE TABLE

  • Luo taulukon


Esim:

CREATE TABLE Products ( id INTEGER PRIMARY KEY, name TEXT, price INTEGER );

Luotiin taulukko, jossa on kolme saraketta: id, name ja price


25.0.2 INSERT INTO

  • lisää uuden rivin taulukkoon

Esim

INSERT INTO Products (name, price) VALUES ('retiisi', 7);


25.0.3 SELECT

  • haetaan tietoa tietystä taulusta

SELECT * FROM Products;

  • tähtimerkki tarkoittaa, että haetaan kaikkea

SELECT name FROM Products;

  • valitsee sarakkeen name taulusta products
SELECT name, price FROM Products;
  • hakee kahdesta sarakkeesta name ja price


25.0.4 WHERE lisää ehdon kyselyyn

SELECT * FROM Products WHERE name = 'lanttu';
  • hakee kaiken Products taulusta, jossa nimi on lanttu


SELECT * FROM Products WHERE price >= 4 AND price <= 6;
  • hakee kaiken Products taulusta ehdolla, että price on suurempi tai yhtäsuuri kuin 4 JA pienempi tai yhtäsuuri kuin 6


<> Tarkoittaa erisuuruutta

SELECT * FROM Products WHERE price <> 4;
  • antaa tuloksena erisuuret kuin 4


25.0.5 ORDER BY

  • järjestää tulostaulun tiettyyn järjestykseen

Esim.

SELECT * FROM Products ORDER BY name;
  • Järjestää sarakkeen name mukaan aakkosjärjestykseen

DESC komennolla voi kääntää järjestyksen laskevaksi

SELECT * FROM Products ORDER BY name DESC;

ASC komennolla nousevaksi, mutta tämä on yleensä oletuksena, joten ei tarvitse lähtökohtaisesti merkata


25.0.6 SELECT DISTINCT

  • antaa tuloksena vain erilaiset rivit
SELECT DISTINCT price FROM Products;


25.0.7 LIMIT

  • rajoittaa tulostauluun tulevien rivien määrän

LIMIT 3

  • Näyttää vain kolme ensimmäistä riviä
SELECT * FROM Products ORDER BY price LIMIT 3 OFFSET 1;
  • OFFSET siirtää rajoituksen alkua annetulla määrällä rivejä eteenpäin. Tässä esimerkissä näytetään siis vain rivit 2, 3 ja 4


25.0.8 UPDATE

  • muuttaa haluttuja taulun rivejä. Jos WHERE ehtoa ei anneta, niin vaikuttaa koko tauluun
UPDATE Products SET price = 6 WHERE id = 2;
  • muuttaa id 2 rivin price arvoksi 6
UPDATE Products SET name = 'ananas', price = 6 WHERE id = 2;

  • Muuttaa id 2 rivin name arvoksi ananas ja price arvoksi kuusi

  • kaksi SET komentoa on eroteltuna pilkulla


25.0.9 DELETE FROM

DELETE FROM Products WHERE id = 5;
  • Poistaa id 5 rivin

25.0.10 DROP TABLE

  • poistaa koko taulun


25.0.11 Yhteenveto / aggregaattifunktiot

  • COUNT(): rivien määrä

  • SUM(): arvojen summa

  • MIN(): pienin arvo

  • MAX(): suurin arvo

  • AVG(): arvojen keskiarvo


SELECT COUNT(*) FROM Products WHERE price = 4;
  • laskee Procusts taulukon rivien lukumäärän, joissa price on 4
SELECT MIN(price), MAX(price) FROM Products;
  • Hakee Products taulun minimi ja maksimihinnat

DISTINCT komennolla saadaan laskettua montako eri arvoa tietyssä sarakkeessa on

SELECT COUNT(DISTINCT price) FROM Products;


25.0.12 IFNULL()

Muutetaan puuttuvat arvot nolliksi

SELECT IFNULL(SUM(price), 0) FROM Products;
  • IFNULL(annettava komento() , puuttuvan arvon korvaava arvo)


25.0.13 GROUP BY

  • komennolla jaetaan rivit ryhmiin annetun sarakkeen mukaan ja lasketaan aggrekaattifunktio jokaiselle ryhmälle erikseen
SELECT company, COUNT(*) FROM Employees GROUP BY company;
  • Jakaa Employees taulun ryhmittäin company sarakkeen mukaan ja laskee rivien lukumäärän ryhmittäin


25.0.14 HAVING

  • Rajaa tuloksia GROUP BY ryhmittelyn jälkeen

Esimerkiksi seuraava kysely hakee yritykset, joissa on ainakin kaksi työntekijää:

SELECT
  company, COUNT(*)
FROM
  Employees
GROUP BY
  company
HAVING
  COUNT(*) >= 2;
company  COUNT(*)
-------  --------
Amazon   2       
Google   3

Voimme myös käyttää koostefunktiota vain HAVING-osassa:

SELECT
  company
FROM
  Employees
GROUP BY
  company
HAVING
  COUNT(*) >= 2;
company
-------
Amazon    
Google


25.0.15 IN

Lauseke x IN (...) on tosi, jos x on jokin annetuista arvoista. Esimerkiksi kysely

SELECT
  SUM(price)
FROM
  Products
WHERE
  name IN ('lanttu', 'nauris', 'selleri');

hakee lantun, nauriin ja sellerin yhteishinnan.

  • Eli IN operaattorilla saa haettua tietyn asian sisältävät kohteet.


25.0.16 LIKE

Lauseke a LIKE p on tosi, jos merkkijono a vastaa kuvausta p. Kuvauksessa voi käyttää erikoismerkkejä:

  • Merkki: _ tarkoittaa mitä tahansa yksittäistä merkkiä

  • Merkki: % tarkoittaa mitä tahansa määrää mitä tahansa merkkejä.

SELECT * FROM Products WHERE name LIKE '%aa%';

Kysely hakee Products taulusta kohteet sarakkeesta name, jotka sisältävät merkkijonon ‘aa’.


25.0.17 FUNKTIOT

Lausekkeiden osana voi esiintyä funktioita samaan tapaan kuin ohjelmoinnissa. Tässä on esimerkkinä joitakin SQLiten funktioita:

  • ABS(x): luvun x itseisarvo

  • LENGTH(s): merkkijonon s pituus

  • LOWER(s): merkkijono s pienillä kirjaimilla

  • MAX(x, y): suurempi luvuista x ja y

  • MIN(x, y): pienempi luvuista x ja y

  • RANDOM(): satunnainen luku

  • ROUND(x, d): luku x pyöristettynä d desimaalin tarkkuudelle

  • SUBSTR(s, a, b): merkkijonon s kohdasta a alkaen b merkkiä

    • Hakee aliosan merkkijonosta

  • UPPER(s): merkkijono s suurilla kirjaimilla


25.0.18 Kyselyn yleiskuva

SQL-kyselyn yleiskuva on seuraava:

SELECT -> FROM -> WHERE -> GROUP BY -> HAVING -> ORDER BY -> LIMIT

Kyselystä riippuu, mitkä näistä osista siinä esiintyvät. Tämä on kuitenkin aina järjestys, jossa kyselyn osat sijaitsevat toisiinsa nähden.


25.0.19 SQLITE käyttäminen

Macilla SQlite tulkki avataan päätteen kautta.

  • Etsi “pääte” spotlightista ja avaa se

  • Syötä päätteeseen komento: sqlite3

  • Tulkki avautuu

Oletuksena tulkki avaa uuden tyhjän tietokannan, joka häviää, kun pääte suljetaan. Käynnistyksen yhteydessä voi antaa tiedostonimen, jolloin tulkkiin syötetyt asiat tallennetaan siihen. Vaihtoehtoisesti voi syöttää siihen olemassaolevan tietokannan nimen, jolloin se avataan. Tulkki toimii käyttäjät kansiossa (aaropohjalainen), joten tietokanta täytyy joko siirtää sinne tai sen eteen täytyy syöttää vaadittava tiedostopolku.

  • Jos avaa pelkästään sqlite 3 komennolla tyhjän tulkin niin saa avattua databasen komennolla .open “TIEDOSTONIMI.db”


  • .mode table

    • komennolla saa tulkissa taulut tulostumaan selkeämmässä muodossa

  • .mode column

    • jokaisella sarakkeella on kiinteä leveys

  • .headers on

    • sarakkeiden nimet näytetään

  • .quit

    • komennolla saa suljettua tulkin

  • .tables

    • näyttää kaikki tietokannan taulut


25.0.20 Sarakkeiden tietotyypit

INTEGER

  • kokonaisluku

TEXT

  • merkkijono

TIMESTAMP

  • ajan hetki

REAL

  • liukuluku eli käytännössä desimaaliluku

BLOB

  • raakadata eli esim. mp3, mp4, jpeg, png, pdf, zip ynnä muut tiedostot

VARCHAR

  • SQL:n perinteinen tapa tallettaa merkkijono. Siitä huono, että vaatii maksimipituuden määrityksen. Esim. VARCHAR(10) tarkoittaa, että merkkijonossa voi olla max 10 merkkiä. TEXT tyypissä ei tarvitse määrittää maksimimäärää merkeille, joten se on helpompi.

PRIMARY KEY

  • tämä ei ole tietotyyppi, vaan taulun pääavain. Sarake, joka määritetään PRIMARY KEY:ksi yksilöi taulun jokaisen rivin eli millään kahdella taulun rivillä ei voi olla samaa arvoa PRIMARY KEY sarakkeessa. Yleensä PRIMARY KEY on kokonaislukumuotoinen (INTEGER) id numero.

    • Pääavainsarakkeelle yleensä halutaan juokseva numerointi. SQLitessä INTEGER tyyppinen PRIMARY KEY sarake saa juoksevan numeroinnin automaattisesti. Eri tietokannoissa se voi toimia eri tavalla.
